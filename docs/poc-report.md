## 3. 关键发现（实现者必读）

1. **北京没有"物理类一分一段表"**：官方只发全体考生一张表；500-600 用户直接查全体表位次即可（需求 D5 口径已确认，无需改动）
2. **HTML/PDF 双通道均可用**：bjeea HTML 页可被读取转换完整表格；2025 走 PDF 更稳（单文件）
3. **2023 低分段（465 以下）暂缺**：官方页低分区为 10 分一段统计，与高分段逐分制式不同；不影响 500-600 主区间，标注"低分段待补"即可
4. **2027 选科要求采用山东通用版**（sdzk.cn 发布、适用全国、644 页覆盖全国院校）——比北京线下"大报纸"更易机器解析；北京与山东同为 3+3 模式，选科口径一致
5. **合规 OK**：抓取仅使用官方公开页面/PDF，频率极低（非批量），无反爬验证码阻断
